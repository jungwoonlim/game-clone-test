## 세 줄 요약

- **엔진은 Godot 4.** 세 후보 중 2D를 1급으로 취급하는 유일한 엔진이고, 이 저장소에서 헤드리스 자동화가 이미 검증됐습니다
- **`core/`는 렌더링을 모릅니다.** 그래야 2.5D 리메이크가 재작성이 아니라 뷰 교체가 됩니다
- **밸런스는 눈이 아니라 시뮬레이션으로 잡습니다.** 전투를 시드 고정으로 1000판 돌려 승률과 필요 걸음 수를 뽑습니다

## 원작 수치에 대하여

전투 공식과 데이터는 **출처마다 충돌합니다.** (예: 크리티컬이 "1/32 고정·방어무시"인지 "민첩/64·2배"인지) 그래서 모든 수치에 검증 상태(✅ / ⚠️ / ❓)를 달아두고, 공식과 상수는 한 파일에만 모아 나중에 데이터만 고칠 수 있게 합니다. 자세한 건 [02-SYSTEMS.md](docs/02-SYSTEMS.md).
