# 05. 로드맵

각 마일스톤은 **완료 기준(DoD)**을 만족해야 다음으로 넘어갑니다. 기준은 전부 "돌려서 확인할 수 있는 것"으로 씁니다.

---

## M0. 기반 + 수치 검증

프로젝트 골격과 데이터 층. **화면에 아무것도 안 나와도 됩니다.**

- Godot 프로젝트 생성, `core/` · `view_2d/` 폴더 분리
- `Resource` 스키마 전부 정의 (→ `03-DATA.md` 1절)
- 플레이스홀더 데이터 입력
- `core/rng.gd` — 시드 주입형 난수
- `tools/validate_data.gd` — 정합성 검사
- **원작 수치 검증** — `02-SYSTEMS.md` 말미의 검증 목록 소화

**DoD**
- `validate_data.gd`가 exit 0
- 검증 목록의 각 항목이 ✅ 또는 "확정 불가, 이 값으로 간다"로 판정됨

> 수치 검증을 여기 두는 이유: 전투를 다 짜고 나서 공식이 틀린 걸 알면 밸런스 작업이 통째로 날아갑니다.

---

## M1. 전투 (화면 없이)

전투 시스템 전체를 순수 로직으로. **뷰 없이 완성합니다.**

- `battle_state.gd` 상태머신
- `formulas.gd` — 통상공격, 크리티컬, 선공, 도망
- 주문 10종 효과
- 상태이상 (수면/주문봉인)
- 몬스터 행동 테이블 추첨
- EXP·골드 획득, 레벨업, 주문 습득
- `tools/simulate_balance.gd`

**DoD**
- 같은 시드로 1000회 돌려 결과가 완전히 동일
- 밸런스 리포트 출력 (레벨×몬스터 승률표, 보스 격파 최소 레벨, 필요 전투 횟수)
- 무한 루프·데드락 0건

---

## M2. 필드 이동

- 그리드 이동, 통행 판정, 걸음 수
- `TileMapLayer` 기반 맵 렌더링, 카메라 추적
- 맵 전환 (계단/문)
- 인카운터 추첨 → 전투 진입 (전투 화면은 아직 텍스트)
- 늪 지형 데미지

**DoD**
- 마을 ↔ 필드 ↔ 던전을 걸어서 오갈 수 있음
- 인카운터가 발생하고 M1의 전투가 실제로 해결됨

---

## M3. 전투 화면 + UI

M1의 이벤트 목록을 화면으로 연출합니다.

- 메시지 창 (한 글자씩 출력, 페이지 넘김)
- 커맨드 창 (필드/전투)
- 스테이터스 창
- 전투 배경, 몬스터 표시, 피격 연출
- 레벨업 / 주문 습득 연출

**DoD**
- 첫 전투부터 레벨업까지 **키보드만으로** 진행 가능
- core 코드 변경 0줄 (이 단계는 순수하게 뷰 작업이어야 함)

---

## M4. 마을

- NPC 대화 (대화 트리, 이벤트 플래그)
- 무기점 / 방어구점 / 도구점 — 구입·판매
- 여관 — 회복
- 왕 — 세이브 / 사망 시 부활 (골드 절반 상실)
- 인벤토리, 장비 교체

**DoD**
- 골드를 벌어 장비를 사고, 여관에서 자고, 세이브 후 재시작하면 상태가 복원됨
- 사망 → 부활 경로가 동작

---

## M5. 던전 + 보스

- 던전 시야 제한, 횃불 / Radiant
- 보물상자
- 2층 구조, 계단
- 보스 전투 (도망 불가, 크리티컬 불가, 2페이즈)

**DoD**
- **세로 슬라이스가 처음부터 끝까지 플레이됨** — 시작 → 성장 → 장비 → 던전 → 보스 격파
- 시뮬레이션이 예측한 권장 레벨과 실제 플레이 체감이 크게 어긋나지 않음

---

## M6. 다듬기

- 사운드 (전투, 레벨업, 메뉴)
- CC0 타일셋/스프라이트로 아트 교체
- 타이틀 화면, 설정 (볼륨, 창 모드)
- 밸런스 최종 조정

**DoD**
- 처음 보는 사람이 설명 없이 보스까지 도달 가능

---

## M7 이후. 2.5D 리메이크

**M5 완료 전에는 착수하지 않습니다.**

- `view_3d/` 신설, `view_2d/`는 남겨둠 (비교·롤백용)
- 3D 배경 + `Sprite3D` 빌보드 캐릭터
- 기울인 직교 카메라, 틸트시프트 DOF, 글로우
- `MapData.elevation` 활용

**DoD**
- `core/` 코드 변경 0줄로 2.5D 렌더링이 동작
- 이게 안 되면 M0~M5에서 규칙이 깨진 것이므로, 그 지점을 찾아 고치는 게 먼저입니다

---

## 우선순위 원칙

범위 판단이 애매할 때 아래 순서로 자릅니다.

1. **시스템 > 콘텐츠** — 몬스터 종류를 늘리기 전에 상태이상을 먼저 완성
2. **로직 > 연출** — 전투가 맞게 돌아간 다음에 이펙트
3. **세로 슬라이스 > 넓이** — 마을 2개보다 마을 1개 + 던전 1개 + 보스
4. **자동 검증 > 수동 확인** — 시뮬레이션으로 잡을 수 있으면 플레이로 잡지 않음
