# 09. 2.5D 리메이크 (M7)

`05-ROADMAP.md`의 M7 완료 기준은 하나였습니다.

> **`core/` 코드 변경 0줄로 2.5D 렌더링이 동작**
> 이게 안 되면 M0~M5에서 규칙이 깨진 것이므로, 그 지점을 찾아 고치는 게 먼저입니다.

**달성했습니다.** 이 마일스톤의 커밋에서 `git diff --stat -- core/`는 비어 있습니다.

## 무엇을 바꿨고 무엇을 안 바꿨나

| | |
| --- | --- |
| `core/` | **변경 0줄** |
| `scenes/main.gd` (컨트롤러) | **2줄** — `extends Node2D` → `extends Node`, `_field: Node2D` → `_field: Node` |
| `view_2d/` | UI를 `game_ui.tscn`으로 추출 (두 씬이 공유), 배경 밴드 틈 수정 |
| 신규 | `view_3d/`, `scenes/main_3d.tscn`, 프롭 아틀라스 |

컨트롤러 2줄이 전부인 이유는, `main.gd`가 필드 뷰에 대해 **아는 것이 메서드 7개뿐**이기 때문입니다.

```
render_map · snap_hero · walk_hero · face_hero · is_walking · set_sight · set_cell_terrain
```

`view_3d/field/field_view_3d.gd`가 같은 이름으로 같은 일을 하면, 컨트롤러는 자기가 무엇을
그리고 있는지 몰라도 됩니다. `tools/test_architecture.gd`가 이 대응을 **자동으로 검사합니다** —
컨트롤러에서 `_field.xxx(` 호출을 정규식으로 긁어 양쪽 뷰에 모두 있는지 확인합니다.

## 렌더러 제약

개발 환경에 Vulkan ICD가 없어 **Forward+를 쓸 수 없었습니다.** 그래서 3D도
`gl_compatibility`에서 돌아갑니다. 결과:

| HD-2D 요소 | 상태 |
| --- | --- |
| 3D 공간 + 2D 스프라이트 | ✅ |
| 기울인 좁은 화각 카메라 | ✅ |
| 그림자, 글로우 | ✅ |
| 피사계심도(틸트시프트) | ⚠️ **직접 구현** — Compatibility에는 DOF가 없어 `view_3d/post/tilt_shift.gdshader`로 9탭 블러 + 비네트 |

## 어떻게 그리는가

- **지면**: 맵 전체를 하나의 `ArrayMesh`로. 타일마다 윗면 쿼드 하나, 이웃이 낮은 쪽에만
  옆면. **UV는 2D 뷰가 쓰는 것과 같은 16×16 아틀라스를 가리킵니다** — 타일은 그림을
  그대로 유지한 채 높이만 얻습니다. 이게 HD-2D의 핵심입니다: 2D 아트, 3D 공간
- **높이**: `Terrain3D.PROFILE`의 지형별 높이 + `MapData.elevation`.
  **M0에서 "2D 렌더러는 무시하지만 나중을 위해" 넣어둔 그 필드를 여기서 처음 씁니다**
- **캐릭터**: 전체 빌보드(`BILLBOARD_ENABLED`). Y축 빌보드는 47° 카메라에서
  스프라이트가 뒤로 누운 것처럼 보입니다
- **지형지물**: 나무·집·동굴·문·상자는 Y축 빌보드. 배경이 투명한 별도 아틀라스
  (`terrain_props.png`)를 씁니다 — 서 있는 빌보드가 자기 발밑 땅을 같이 들고 있으면 안 됩니다
- **던전 어둠**: 2D의 검은 오버레이가 3D에서는 **랜턴 + 안개**가 됩니다.
  같은 정보를, 매체에 맞는 방식으로

## 전환 방법

설정의 **VIEW** 항목에서 `2D` / `2.5D`를 고르면 타이틀이 해당 씬을 엽니다.
빌드가 아니라 씬 경로 하나 차이입니다.

## 이번에 드러난 것

3D로 옮기니 2D에서는 안 보이던 버그가 둘 나왔습니다.

1. **전투 배경의 밴드 틈** — 하늘 밴드를 `horizon * t`로 배치했는데 간격이 밴드 높이보다
   커서 1~2px 틈이 있었습니다. 2D에서는 뒤가 어두워 안 보이다가, 3D의 밝은 장면이
   비치면서 가로 줄무늬로 드러났습니다
2. **주인공이 땅에 반쯤 묻힘** — 스프라이트는 원점 중심이라 지면에 세우려면 절반 높이만큼
   올려야 하는데, NPC에는 했고 주인공에는 빠뜨렸습니다

## 남은 것

- Forward+가 가능한 환경에서는 자체 틸트시프트를 엔진 DOF로 교체
- 전투도 3D 무대로 (현재는 2D UI 창을 그대로 사용 — 의도된 선택이지만 HD-2D 원작은 3D 무대를 씁니다)
- `elevation`을 실제 맵 데이터에 활용 (현재 전 맵 0)
