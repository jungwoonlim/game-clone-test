# 06. 원작 수치 검증 기록 (M0)

`05-ROADMAP.md`의 M0 완료 기준은 "검증 목록의 각 항목이 ✅ 또는 **'확정 불가, 이 값으로 간다'**로 판정됨"입니다. 이 문서가 그 판정 기록입니다.

## 무엇을 시도했나

| 출처 | 결과 |
| --- | --- |
| Steamworks 스타일 공식 문서 | 원작엔 존재하지 않음 |
| GameFAQs Formula Guide (Ryan8bit) | 검색 요약으로만 확인, 본문 접근 차단 |
| gamercorner Game Systems | 본문 접근 차단 |
| Mike's RPG Center 레벨 표 | 본문 접근 차단, 검색 요약은 열이 뒤섞여 신뢰 불가 |
| `TheAnsarya/dragon-warrior-info` GAME_FORMULAS.md | 전문 확보. **다만 정설과 충돌** (아래) |
| `nmikstas/dragon-warrior-disassembly` Bank00~03.asm | 전투 루틴이 있을 Bank03이 fetch 단계에서 잘려 확보 실패 |

**결론: 디스어셈블 원본 대조는 이번 환경에서 완료하지 못했습니다.** 따라서 값마다 판정을 남기고, 나중에 한 곳만 고치면 되도록 격리했습니다.

### ⚠️ 출처 충돌 — 하나를 골랐고, 근거를 남김

| 항목 | 채택 | 기각 | 이유 |
| --- | --- | --- | --- |
| 회심의 일격 | **1/32 고정, 방어 무시, 공격력의 50~100%** | 민첩/64 확률, 통상 데미지 2배 | 1/32 쪽이 다수 출처에서 일관되게 등장. 기각한 쪽은 다른 항목에서도 정설과 어긋남 |

| EXP 테이블 | **7, 23, 47, 110, … 65535 (29개)** | - | 두 출처가 일치하나 ROM 대조 전까지 ⚠️ 유지 |

### ❓ 미검증 — 플레이스홀더로 두고 시뮬레이션으로 조율

- 선공 판정 계수
- 도망 성공 공식의 기반값과 계수
- 상태이상 저항값 체계 (몬스터별 실수치)
- **레벨별 힘/민첩/HP/MP 절대 테이블 전체**
- **몬스터 스탯 전체**
- 필드 주문(Radiant/Outside/Return/Repel)의 MP 비용

## 어떻게 격리했나

> 모든 전투 공식과 상수는 **`core/battle/formulas.gd` 한 파일**에만 있고, 나머지 수치는 전부 `core/data/*.tres`에 있습니다.

`formulas.gd`의 각 상수에는 `[OK]` / `[PICKED]` / `[GUESS]` 라벨이 붙어 있습니다. 나중에 ROM 값을 확보하면 **로직은 한 줄도 건드리지 않고** 상수와 `.tres`만 고치면 됩니다.

## 플레이스홀더 수치는 '틀린 값'이 아니라 '조율된 값'

몬스터 스탯과 보상은 원작 복사가 아니라 **시뮬레이션으로 맞춘 값**입니다.

처음에는 원작의 초반 보상(슬라임 1 EXP 수준)을 그대로 썼는데, `simulate_balance.gd`가 **보스까지 약 8,900전투 / 114,000보**를 보고했습니다. 원작 EXP 커브는 약 40종의 몬스터가 여러 지역에 퍼져 있는 걸 전제로 설계됐고, 이 세로 슬라이스에는 8종뿐이기 때문입니다.

EXP 커브(⚠️, 원작 데이터)는 그대로 두고 **몬스터 보상(❓, 플레이스홀더)만** 올려 약 **577전투 / 5,952보**로 맞췄습니다. 보스 격파 가능 레벨은 16~17로, 원작 권장 레벨(18~20)에 가깝습니다.

현재 수치는 `07-BALANCE_REPORT.md`에서 확인할 수 있습니다.
