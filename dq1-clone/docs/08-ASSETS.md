# 08. 에셋 파이프라인

이 프로젝트에는 **외부에서 가져온 에셋이 하나도 없습니다.** 타일, 스프라이트,
효과음, 음악이 전부 `tools/`의 생성기에서 나옵니다.

원래 계획(`05-ROADMAP.md` M6)은 CC0 타일셋을 가져다 쓰는 것이었지만, 개발 환경에서
외부 에셋을 받을 수 없었습니다. 그래서 **받아온 척하는 대신 전부 생성했습니다.**
출처가 불분명한 에셋을 커밋하는 것보다 이쪽이 정직하고, 라이선스 문제도 없습니다.

## 무엇이 생성되는가

| 산출물 | 생성기 | 내용 |
| --- | --- | --- |
| `view_2d/field/terrain_tiles.png` | `tools/build_tiles.gd` | 16×16 지형 타일 15종 |
| `assets/art/monsters.png` | `tools/build_sprites.gd` | 24×24 몬스터 9종 |
| `assets/art/hero.png` | `tools/build_sprites.gd` | 16×16, 4방향 × 2프레임 |
| `assets/art/npcs.png` | `tools/build_sprites.gd` | 16×16 NPC 4역할 |
| `assets/audio/sfx_*.tres` | `tools/build_audio.gd` | 효과음 19종 |
| `assets/audio/bgm_*.tres` | `tools/build_audio.gd` | 루프 BGM 5곡 |

## 재생성

```bash
G=godot
$G --headless --path . --script res://tools/build_tiles.gd
$G --headless --path . --script res://tools/build_sprites.gd
$G --headless --path . --script res://tools/build_audio.gd
$G --headless --path . --import
```

**생성기는 전부 결정적입니다** — 시드가 고정되어 있어 몇 번을 돌려도 바이트 단위로
같은 결과가 나옵니다. 매 빌드마다 노이즈가 달라지면 모든 커밋이 아트 변경처럼
보이게 되기 때문입니다.

## 어떻게 만드는가

### 스프라이트 — 프리미티브 + 후처리

픽셀을 하나씩 찍지 않습니다. 종마다 **실루엣만** 타원·삼각형·사각형으로 기술하고,
공통 후처리를 돌립니다.

1. 실루엣을 인덱스 그리드에 채운다
2. 아래쪽 1/6을 어두운 색으로, 좌상단에 하이라이트를 찍는다
3. 실루엣에 인접한 빈 픽셀을 전부 외곽선으로 칠한다

3번이 핵심입니다. 외곽선 패스 하나가 "색칠한 도형"을 "스프라이트"로 바꿔주고,
종을 추가해도 추가 비용이 0입니다.

### 오디오 — 펄스·삼각파·노이즈

`build_audio.gd`가 float 버퍼에 파형을 더한 뒤 16비트 PCM으로 굽습니다.

- **펄스파** — 듀티 0.5는 속이 빈 사각파, 0.125는 NES 리드의 가는 소리
- **삼각파** — 베이스
- **노이즈** — 1극 로우패스를 통과시켜 클릭이 아니라 타격음/바람소리로 들리게
- 마지막에 소프트 클립을 걸어 여러 성부가 겹쳐도 깨지지 않게

음악은 `[음표, 박]` 배열과 마디별 베이스 루트만 적으면 `_compose()`가 렌더합니다.

**`.wav`가 아니라 `.tres`로 저장합니다.** 루프 지점이 리소스 안에 들어가서
임포트 설정을 건드리지 않고도 BGM이 끊김 없이 반복됩니다.

## 검증

`tools/test_presentation.gd`가 잡습니다.

- 모든 스트림의 피크·RMS를 측정 — **무음과 클리핑은 둘 다 버그처럼 들리는데
  다른 어디에도 드러나지 않습니다**
- BGM은 `LOOP_FORWARD`인지, 2초 이상인지
- 시트 크기가 몬스터 수 · 방향 수 · 지형 종류 수와 맞는지
- 모든 맵이 쓰는 지형 id가 아틀라스 안에 있는지
- **사운드 이름 대조** — `view_2d/`와 `scenes/`의 모든 `"sfx_*"` / `"bgm_*"` 문자열을
  정규식으로 긁어 실제 파일과 맞춰봅니다. 오타 난 사운드 이름은 런타임에 조용히
  무시되고 스크린샷에도 안 남기 때문에, 이걸 자동으로 잡지 않으면 영영 모릅니다

## 글꼴만은 받아 옵니다

다른 에셋은 전부 생성하지만 한글 글꼴은 생성할 수 없습니다 — 11,172자를 11픽셀에서
읽히게 만드는 건 이 저장소가 할 일이 아닙니다.

`tools/build_font.py`가 Noto Sans KR(SIL OFL 1.1)을 Google Fonts에서 받아,
**이 게임이 실제로 화면에 찍는 380자만 남기고 잘라** `assets/fonts/`에 넣습니다.
한 벌에 2.4MB → **52KB**. 문자열을 추가했으면 다시 돌려야 합니다. 글리프가 없는
글자는 빈 네모로 그려집니다.

글꼴은 `assets/theme/dq_theme.tres` **안에 구워 넣습니다.** 테마가 `.ttf`를
참조하면 그건 파일을 가리키는 게 아니라 임포터가 만든 산출물(`.godot/` 아래,
저장소에 없음)을 가리킵니다. 그러면 새로 clone한 프로젝트는 임포트를 두 번
해야 켜졌습니다 — 한 번은 글꼴을 만들고, 한 번은 테마가 그걸 찾고. 그 사이에는
테마 없이 뜨고, 클래스 이름을 쓰는 스크립트가 전부 파스 에러를 냈습니다.
`test_presentation.gd`가 테마에 `[ext_resource]`가 있으면 실패합니다.

메뉴 커서와 볼륨 막대는 글자가 아니라 도형으로 그립니다. 자세한 이유는
[11-I18N.md](11-I18N.md).

## 나중에 진짜 에셋으로 바꾸려면

교체 지점이 좁게 설계되어 있습니다.

| 바꿀 것 | 방법 |
| --- | --- |
| 타일 | `terrain_tiles.png`를 같은 레이아웃(16×16 × 15칸)으로 교체 |
| 몬스터 | `monsters.png`를 24×24 × 9칸으로 교체. 열 순서는 `monster_sprite.gd`의 `COLUMNS` |
| 캐릭터 | `hero.png`(2프레임 × 4방향), `npcs.png`(4역할) |
| 사운드 | `assets/audio/`의 같은 이름 파일을 교체 (`.tres` 또는 임포트된 `.wav`) |
| 글꼴 | `assets/fonts/`의 `.ttf`를 교체하고 `build_font.gd` 재실행 |

코드 변경은 필요 없습니다. 생성기를 지워도 게임은 그대로 돌아갑니다.
