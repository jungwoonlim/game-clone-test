# game-clone-test

게임 클론 습작 모음. **프로젝트마다 최상위 폴더 하나**를 쓰고, 각 폴더는 서로
의존하지 않는 독립 프로젝트입니다.

| 프로젝트 | 엔진 | 설명 |
| --- | --- | --- |
| [`suika-game/`](suika-game/) | Godot 4 | 수박게임(Suika Game) 스타일 물리 기반 과일 합치기 |
| [`dq1-clone/`](dq1-clone/) | Godot 4 | 드래곤 퀘스트 1 시스템 클론 (2D → 2.5D). M0~M2 완료 — 이동·인카운터·전투 동작 |

## 새 클론 추가할 때

```
<project-name>/
├── README.md      # 무엇을, 어떤 엔진으로, 어떻게 실행하는지
├── docs/          # 개발 노트, 출시 노트
└── ...            # 엔진별 프로젝트 파일
```

- 엔진 캐시(`.godot/`, `Library/` 등)와 빌드 산출물은 각 프로젝트의 `.gitignore`로 제외합니다
- 가능하면 에디터 없이 돌릴 수 있는 헤드리스 스모크 테스트를 하나 넣어둡니다
  (`suika-game/tools/smoke_test.gd` 참고)
